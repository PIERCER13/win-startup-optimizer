# Windows Startup Optimizer

[English Version](./README.en.md)

> **Linguagem / Stack:** `PowerShell` | **Autor:** `piercer`

## O que faz

Audita itens de inicialização (Registry Run, Startup Folder e serviços de terceiros) com status de assinatura.

## Como executar

```bash
start.bat  # ou powershell -File win_startup_optimizer.ps1
```
