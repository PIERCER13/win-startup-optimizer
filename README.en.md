# Windows Startup Optimizer

[Versão em Português](./README.md)

## Overview

Audits Windows startup items (Registry Run, Startup Folder, and 3rd-party auto services) with signature status.

## How to run

```bash
start.bat  # ou powershell -File win_startup_optimizer.ps1
```
